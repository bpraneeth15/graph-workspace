# Roadmap

This roadmap keeps future work organized. Items can move as the product direction changes.

## Near Term

- Improve the 3D object controls for cubes and surfaces.
- Add better labels and editable metadata for every 3D object.
- Improve 3D top-down view so it can show more object details.
- Add export/import for workspace captures.
- Continue splitting `App.tsx` into smaller feature modules.
- Improve touch and Apple Pencil behavior for iPad use.

## Graphing And Math

- Add more regression tools beyond least squares.
- Add polynomial, exponential, logarithmic, and custom curve fitting.
- Add residual plots and error metrics.
- Add smarter data parsing for copied tables and CSV-like input.
- Add richer statistics in the calculator.

## 3D And Visualization

- Add more editable solids.
- Add parametric 3D curves.
- Add plane and vector tools.
- Add real-time surface intersections.
- Add contour maps for multiple surfaces.
- Add GPU-focused performance controls for dense surfaces.

## Product Quality

- Add automated tests for graph math and data parsing.
- Add visual regression checks for grid rendering.
- Add keyboard shortcut documentation inside the app.
- Add structured release notes.
